CLAIMS INTAKE | PRESENTER DEMO KIT

Run from this directory with Python 3.12+; no pip packages, Docker or remote
connection is needed for the local rehearsal. Each target must be a new path.

  python .\prepare.py baseline .\rehearsal\baseline
  python .\prepare.py review-failing .\rehearsal\review-failing
  python .\prepare.py review-fixed .\rehearsal\review-fixed
  python .\prepare.py security-open .\rehearsal\security-open
  python .\prepare.py security-fixed .\rehearsal\security-fixed

From each prepared directory:
  python -m unittest discover -s tests -v
  python .\scan_demo.py --sarif demo-results.sarif

Expected: baseline 3 tests pass, review-failing 5 tests collected with
intentional failures, review-fixed 5 pass. DEMO001 is present in
security-open and absent in security-fixed. The other states retain the
separate audit fixture. The scanner reports findings without failing CI.

sample\work_item.txt is the Project input. sample\.github\workflows\ci.yml
is the optional GitHub check when the sample is provisioned remotely.
The overlays are presenter material: do not commit the kit or reference
fixes to a demo repository. fixtures and evidence are not GitHub output;
see the labels in the evidence folder.

The audit fixture emits only a fixed marker through an injected function.
It does not collect, store or transmit claims or operate a real service.
The policy scanner is a one-rule teaching fixture, not a security audit.
setup\demo-scan.yml.example is inert. Demonstration-only; activate it
only in a separately approved private demo repository if Code Security,
action policies and upload permissions are confirmed. Do not publish
or upload any sample from this package without separate authorization.
